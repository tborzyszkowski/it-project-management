# Zarządzanie projektami IT

Materiały dydaktyczne do laboratoryjnych zajęć z zarządzania projektami IT dla studiów podyplomowych BIM.

## O projekcie

Zajęcia trwają 4 godziny (2 bloki × 2 godziny) i nie wymagają umiejętności programowania. Przez całe zajęcia zespoły realizują wspólny projekt symulacyjny – napisanie krótkiej powieści z pomocą narzędzi AI – co pozwala skupić się na procesie, rolach i narzędziach identycznych jak w prawdziwych projektach IT.

Studenci uczą się metodyk Waterfall, Scrum i Kanban, pracy z backlogiem i tablicą Kanban oraz obsługi narzędzia **Jira** (plan bezpłatny).

## Struktura repozytorium

```
Bloki/
  Blok1-Teoria-Przygotowanie/   # Teoria metodyk, ról i narzędzi; konfiguracja Jira
  Blok2-Sprint-Podsumowanie/    # Sprint, Daily Scrum, Review, Retrospektywa, podsumowanie
Dokumentacja/
  PlanZajec.md                  # Pełny plan zajęć z harmonogramem i materiałami
```

## Wymagania

- Sala z komputerami i dostępem do Internetu
- Konto e-mail (dowolny provider) do rejestracji w Jira
- Brak wymagań programistycznych
